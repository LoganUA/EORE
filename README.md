# MAG Ukraine — EORE Game

Мобільний браузерний застосунок з мінної безпеки (EORE) для MAG Ukraine.
Чотири режими гри на спільній архітектурі: свайп-гра "Безпечно чи
небезпечно", квест "Розслідування" з викликом 101, вікторина "Правда чи
Неправда" і симулятор "Полігон розмінування".

## Структура проєкту

```
index.html                    ← єдина точка входу, чиста розмітка
css/
  styles.css                  ← усі стилі застосунку
js/
  app.js                      ← точка входу: меню, вибір формату, зв'язок режимів
  core/
    state.js                  ← монети, підказки, мова, прогрес полігону (localStorage)
    i18n.js                   ← словники UA/EN + t() хелпер перекладу
    screens.js                ← спільна навігація між екранами
  data/
    decks.js                  ← питання для свайп-гри, квестів і вікторини
  modes/
    swipeGame.js               ← "Безпечно чи небезпечно" + "Правда чи Неправда"
    questGame.js                ← "Розслідування" (розгалужений квест + 101)
    deminingField.js            ← "Полігон розмінування" (новий режим)
tests/
  *.test.mjs                  ← функціональні тести (jsdom, без браузера)
  fixtures/*.html              ← мінімальні DOM-фікстури під кожен тест
```

## Локальний запуск

**Важливо:** `index.html` використовує ES-модулі (`<script type="module">`),
тому браузер заблокує їх, якщо просто відкрити файл подвійним кліком
(`file://…`). Потрібен будь-який локальний сервер:

```bash
# варіант 1 — Node (якщо є npx)
npx serve .

# варіант 2 — Python (майже завжди є з коробки)
python3 -m http.server 8000
```

Потім відкрити `http://localhost:3000` (npx serve) або
`http://localhost:8000` (Python) у браузері.

## Тести

Усі тести — на чистому Node.js через jsdom, браузер не потрібен.

```bash
npm install
npm test
```

Або запустити тести окремо:

```bash
node tests/i18n.test.mjs
node tests/decks.test.mjs
node tests/swipeGame.test.mjs
node tests/questGame.test.mjs
node tests/deminingField.test.mjs
node tests/app.integration.test.mjs
```

Кожен тест реально клікає по DOM-елементах (не просто перевіряє синтаксис)
і завершується або `ALL TESTS PASSED`, або списком конкретних `FAIL:` —
з поясненням, що саме не так.

## Деплой на GitHub Pages

1. Створити репозиторій на GitHub і залити весь вміст цієї папки
   (`index.html` має лежати в корені репозиторію).
2. Settings → Pages → Source → **Deploy from a branch** → гілка `main`,
   папка `/ (root)`.
3. Через 1-2 хвилини сайт буде доступний за адресою
   `https://<username>.github.io/<repo-name>/`.

Оскільки застосунок повністю статичний (жодного бекенду), цього достатньо —
додаткове налаштування серверів не потрібне.

## Прогрес гравця

Монети, підказки, мова інтерфейсу та статистика полігону розмінування
(очищена площа, довідник знайдених загроз) зберігаються в `localStorage`
браузера — автоматично, без реєстрації. Якщо `localStorage` недоступний
(наприклад, приватний режим браузера), застосунок тихо переходить на
зберігання в пам'яті на час сесії, без помилок.

## Як додати новий режим гри

1. Створити `js/modes/newMode.js` за зразком `deminingField.js`:
   - `initNewMode()` — кешує DOM, вішає обробники подій
   - `startNewModeFormat()` — точка входу з екрана вибору формату
   - `refreshNewModeLabels()` — оновлення текстів при зміні мови
   - `registerScreens([...])` на початку `init`, щоб екрани режиму
     потрапили під керування спільної навігації
2. Додати потрібні екрани в `index.html` (за зразком інших `<div class="screen">`).
3. Додати рядки перекладу в `js/core/i18n.js` (в обидва блоки — `uk` і `en`).
4. У `js/app.js`:
   - імпортувати три функції з нового модуля
   - додати картку формату в `screenFormat` (HTML) і обробник кліку
   - викликати `initNewMode()` у `boot()`
   - додати `refreshNewModeLabels()` у `switchLanguage()`
5. За бажанням — написати `tests/newMode.test.mjs` за зразком існуючих.

Жодний із наявних режимів при цьому не змінюється.

## Як додати новий рівень складності або сценарій

- Нові карти для свайп-гри чи вікторини "Правда/Неправда" — додати об'єкти
  у відповідні масиви в `js/data/decks.js` (структура `{icon, answer, uk:{...}, en:{...}}`).
- Новий сценарій квесту — додати новий ключ у `QUESTS` в `js/data/decks.js`
  за зразком наявних (`ageVariants.child/teen/adult`, кожен зі своїм графом
  вузлів `nodes`).
- Нові типи загроз для "Полігону розмінування" — додати об'єкт у
  `THREAT_CATALOG` на початку `js/modes/deminingField.js`.
